# Vectoria

Vectoria is a full, continuously developed vector graphics editor project. It is not an MVP-only application and epic work must not be reduced to MVP slices unless a task explicitly says so.

The MVP/Skeleton described in architecture documents is a delivery milestone used to establish the foundation. It does not limit the target scope of EPIC-00 and later epics. Each epic is implemented against its complete specification, including domain model, UI, persistence, renderer parity, accessibility and regression coverage.

Current work status is tracked in `BACKLOG.md`, `ROADMAP.md` and the files in `epics/`. A feature is complete only when its full epic acceptance criteria are met or its remaining scope is explicitly recorded and approved.
